# Ranking Vote Hub

ユーザー投票と口コミで、施設・作品・スポットをジャンル別にランキング化するUGC対応サービスです。

## Repository Name

ranking-vote-hub

## Domain Candidates

- rankvote.jp
- minrank.jp
- votehub.jp
- oshirank.jp

## Features

- ジャンル別ランキング検索
- 投票・保存・推薦理由投稿
- UGC投稿と確認待ちステータス
- SEO/AIO/LLMO向けFAQ、即答ブロック、構造化データ
- robots.txt / sitemap.xml / llms.txt
- スポンサーランキング、送客、予約、クーポン、アフィリエイト、確認済み掲載の収益導線
